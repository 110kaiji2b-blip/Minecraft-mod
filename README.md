# Swift Skyblock（快適・待ち時間ゼロ スカイブロックMOD）

**Minecraft Forge 1.20.1** 向けの、**単体完結・待ち時間極小化**をコンセプトにしたスカイブロックMODです。  
配布ワールドや前提MOD（他MOD）は一切不要！このMODの `.jar` ファイルを1つ `mods` フォルダに入れるだけで、新規ワールド作成からすぐに快適なスカイブロックを始められます。

---

## 導入方法（とても簡単・3ステップ）

> **必要環境**: Minecraft Java Edition **1.20.1** + **Minecraft Forge 1.20.1**（`47.x` 系全般に対応）  
> **他MODへの依存**: **なし**（単体で動作します。JEIなどのレシピ確認MODと併用するとさらに快適です！）

### Step 1. Minecraft Forge 1.20.1 をインストール
1. [Minecraft Forge 公式サイト (1.20.1)](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html) から **Recommended（推奨版）** の `Installer` をダウンロードします。
2. ダウンロードしたインストーラーを実行し、「**Install client**」を選んでインストールします。
3. Minecraftランチャーを開き、起動構成に「`forge 1.20.1`」が追加されていることを確認します。

### Step 2. MODファイル（`.jar`）を `mods` フォルダへ配置
1. 本リポジトリの **Releases** ページ（またはビルドで生成された `build/libs/swiftskyblock-1.20.1-1.0.0.jar`）から `.jar` ファイルを入手します。
2. Minecraftの `mods` フォルダを開きます：
   - **Windows**: `Win + R` キーを押し、`%appdata%\.minecraft\mods` と入力して Enter
   - **macOS**: Finder で `~/Library/Application Support/minecraft/mods` を開く
   - **Linux**: `~/.minecraft/mods` を開く
   - *(もし `mods` フォルダがなければ新しく作成してください)*
3. 入手した `swiftskyblock-1.20.1-1.0.0.jar` を `mods` フォルダの中にコピーします。

### Step 3. 起動してスカイブロックワールドを作成！
1. ランチャーから **Forge 1.20.1** を選んでゲームを起動します。
2. **「シングルプレイ」→「ワールドを新規作成」** を開きます。
3. **「世界（World）」タブ** を開き、**「ワールドタイプ」** をクリックして **`スカイブロック (Swift Skyblock)`** に切り替えます。
4. 「ワールドを新規作成」を押すと、自動でスターター浮島が生成され、すぐに冒険がスタートします！

> **既存のワールドや配布マップで使いたい場合**:  
> 通常ワールドでもそのまま動作し、チャットで `/sb create` と打つと空中に新しいスターター浮島を生成できます。

## 待ち時間を劇的に減らす主な機能

### 1. 超速成長（スニーク連打＆スプリント成長）
- 苗木や作物、サトウキビ、サボテン、竹、ネザーウォートの近くで **スニーク（Shift）を連打** すると、周囲半径5ブロックの植物が一気に急成長します。
- 苗木なら数秒で立派な木に育つため、初期の木材待ち時間がほぼゼロになります。

### 2. 一括破壊＆奈落ロスト防止
- **スニークしながら原木を伐採**すると、木全体を一括破壊し、**周囲の葉も同時に即回収**します（葉が自然消滅するのを待つ必要がありません）。
- 鉱石や葉、さらに**粉砕ハンマーを持った状態の丸石・砂利・砂・圧縮ブロック**もスニーク採掘で最大64個まで一括粉砕できます。
- 一括破壊したアイテムは**プレイヤーのインベントリ（または足元）へ直接届く**ため、奈落への落下ロストを防ぎます。

### 3. 粉砕ハンマー & 圧縮一括粉砕 & 小石採取
- **小石採取**: 素手＋スニークで土や草ブロックを右クリックすると **小石（Stone Pebble）** を拾えます（4個で丸石1個）。丸石製造機を失敗しても絶対に詰みません。
- **粉砕ハンマー（木・石・鉄・ダイヤ・ネザライト）**:
  - `丸石 / 石` → **砂利** → **砂** → **ダストブロック** へ直接粉砕！
  - `ネザーラック` → **ソウルサンド** へ粉砕！
  - **圧縮ブロック（圧縮丸石・圧縮砂利・圧縮砂）** をハンマーで壊すと **1撃で9個分** ドロップします！

### 4. 高速ふるい（Rapid Sieve）
- 序盤からクモ湧き待ちなしで作れる（板材＋葉ブロック＋棒、または糸でも作成可能）。
- 土・砂利・砂・ダスト・ソウルサンドを持って：
  - **通常右クリック**: 最大8個を一瞬でふるい完了！
  - **スニーク＋右クリック**: **手持ちの1スタック（最大64個）を一瞬で一括ふるい！**
  - **ホッパー自動化対応**: 上/横からホッパーで投入すると高速自動ふるいし、下のチェストへ自動排出します。
- 鉱石（鉄・銅・金・石炭・ラピス・ダイヤ・エメラルド・レッドストーン・クォーツ・古代の残骸）や各種苗木・種・ネザー素材まで幅広く入手可能。

### 5. 高速コンポスター樽（Rapid Compost Barrel）
- 葉・苗木・種・作物・腐肉などを8個入れる（スニークで一括投入）と、**わずか2秒**で **土ブロック** に変換（ホッパー自動化対応）。
- 降雨時は4秒で水が満タンになります。
- **スカイブロック必須のブロック変換**:
  - `水入り樽` ＋ `ダストブロック` → **粘土ブロック**
  - `水入り樽` ＋ `溶岩バケツ`（または逆） → **黒曜石**
  - `溶岩入り樽` ＋ `ダスト` または `レッドストーン` → **ネザーラック**
  - `溶岩入り樽` ＋ `砂` → **ソウルサンド**
  - `溶岩入り樽` ＋ `グロウストーンダスト` → **エンドストーン**

### 6. 時短マシン＆自動化設備
| 設備・アイテム | 効果 |
| :--- | :--- |
| **自動丸石製造機 (Tier 1 / 2 / 3)** | 毎秒 **2個 / 8個 / 32個** の丸石を自動生成。上のチェストに自動搬出。右クリックで1スタック回収、スニーク右クリックで**圧縮丸石として回収**！ |
| **高速かまど (Turbo Furnace)** | バニラかまどの **8倍速精錬** ＆ **燃料効率2倍**。ホッパー連携も完全対応。 |
| **高速溶岩るつぼ (Rapid Crucible)** | たいまつ・マグマブロック・溶岩などの熱源の上に置き丸石を入れると、**0.5〜2秒で溶岩バケツ1杯分**を超速生成！ホッパー＆流体パイプ対応。 |
| **加速ランタン (Acceleration Lantern)** | 周囲半径4ブロック以内の**かまど・自動丸石製造機・ふるい・るつぼ・樽・ホッパー・作物**を **4倍速** に加速！ |
| **懐中時短クロック (Time Pocket Watch)** | 対象ブロックを右クリックすると **+100ティック（5秒分）を即時進行**！ |

### 7. ストレスゼロの安心サポート
- **スカイマグネット（初期チェスト封入）**: インベントリに入れておくだけで周囲12ブロックのアイテムと経験値を自動吸引（右クリックでON/OFF）。
- **奈落落下セーフティ**: うっかり奈落（Y < -64）に落ちても、全ロスせず自動的に島のホーム地点へ安全帰還（落下ダメージ無効＆足場チェック付き）。
- **進捗ツリー & ガイドブック**: ゲーム内の進捗画面と初期チェストのガイドで次に作るべき設備が一目で分かります。

## コマンド一覧

`/skyblock` または短縮形の `/sb` が使えます。

- `/sb create` — 新しいスターター浮島を生成してテレポート
- `/sb home` — 自分の島のホーム地点へ帰還
- `/sb sethome` — 現在地を島のホーム地点に設定
- `/sb guide` — 進め方と時短テクニック一覧をチャットに表示

---

## コンフィグ設定

初回起動後に `config/swiftskyblock-common.toml` が生成されます。  
スニーク成長の半径・強さ、一括破壊の上限数、奈落セーフティのON/OFF・ダメージ有無、高速かまどの倍率、加速ランタンの範囲・倍率などを自由にカスタマイズできます。

## 開発者向け：ソースコードからのビルド方法

Java 17（JDK 17）がインストールされた環境で、プロジェクトルートから以下を実行します：

```bash
# macOS / Linux
./gradlew build

# Windows
gradlew.bat build
```

ビルドが完了すると `build/libs/swiftskyblock-1.20.1-1.0.0.jar` が生成されます。
